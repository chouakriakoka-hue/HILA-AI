# HILA AI + OpenAI API

## الملفات
- `index.html`: واجهة HILA AI التي تعدّلها في Acode.
- `server/index.js`: خادم Node.js يتصل بـ OpenAI ويحمي مفتاح API.
- `.env.example`: نموذج إعدادات المفتاح.

## التشغيل
1. ثبّت Node.js في بيئة تشغيل مناسبة (على Android يمكن استعمال Termux؛ Acode محرر كود وليس خادماً).
2. افتح مجلد المشروع في بيئة الطرفية.
3. نفّذ: `npm install`
4. انسخ `.env.example` إلى ملف اسمه `.env`.
5. افتح `.env` وضع مفتاحك مكان `ضع_مفتاحك_هنا`، ولا تشارك الملف.
6. نفّذ: `npm start`
7. افتح `index.html` عبر خادم ويب محلي، وليس بالضرورة عبر معاينة file://. الواجهة تتصل بـ `http://localhost:3001/api/chat`.

## تنبيه
- مفتاح API يبقى في `.env` على الخادم فقط، ولا تضعه داخل HTML أو JavaScript.
- استخدام OpenAI API قد يترتب عليه رسوم حسب حسابك واستهلاكك.
- عند نشر الموقع على الإنترنت، انشر الخادم على استضافة آمنة، واستخدم HTTPS وقيّد CORS وأضف حماية من إساءة الاستخدام.
